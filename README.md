# Αθλητικός Σκοπευτικός Όμιλος Καλαμάτας (ΑΣΟΚ)

Επίσημη ιστοσελίδα του Αθλητικού Σκοπευτικού Ομίλου Καλαμάτας — ιδρύθηκε το 1959.

## Δομή

```
.
├── index.html       # Η ιστοσελίδα (single-page React app)
└── uploads/         # Φωτογραφίες & logo
```

Όλο το site είναι ένα αυτόνομο HTML αρχείο που φορτώνει React, ReactDOM και Babel από CDN. Δεν χρειάζεται build step ή server.

## Τοπική προβολή

Άνοιξε το `index.html` σε οποιονδήποτε σύγχρονο browser. Ο χάρτης Google Maps και το Facebook video χρειάζονται διαδίκτυο.

## Hosting στο GitHub Pages

1. Ανέβασε όλο τον φάκελο στο root ενός GitHub repo.
2. Settings → Pages → Source: `Deploy from a branch` → `main` → `/ (root)` → Save.
3. Σε ~1 λεπτό η σελίδα θα είναι διαθέσιμη στη διεύθυνση:
   `https://<username>.github.io/<repo-name>/`

## Σελίδες

- **Αρχική** — Hero, video, παρουσίαση συλλόγου, χάρτης
- **Σύλλογος** — Ιστορία & στοιχεία
- **Gallery** — Φωτογραφίες

- **Πρόγραμμα** — Ωρολόγιο προπονήσεων
